## 1. `openrouterkey.txt` (root, UNTRACKED)

**Status:** File exists at repo root but is **NOT tracked by git** (covered by `.gitignore:6`).
It was never committed to history based on `git log --all -- openrouterkey.txt` returning no results.

**Contains:**
```
openrouter: REDACTED_ROTATED_OPENROUTER_KEY
deepseek:   REDACTED_ROTATED_DEEPSEEK_KEY
```

**Risk:** File is on disk in a git repo. If `.gitignore` is accidentally removed or the file
is explicitly `git add`-ed with `-f`, both keys would be committed.

### Remediation Steps

1. **Rotate the OpenRouter key immediately:**
   - Go to https://openrouter.ai/keys
   - Delete or regenerate the key `REDACTED_ROTATED_OPENROUTER_KEY...`
   - Update `openrouterkey.txt` with the new key.

2. **Rotate the DeepSeek key immediately:**
   - Go to https://platform.deepseek.com/api_keys
   - Revoke `REDACTED_ROTATED_DEEPSEEK_KEY`
   - Update `openrouterkey.txt` with the new key.

3. **Verify the file is gitignored:**
   ```
   git check-ignore -v openrouterkey.txt
   # Expected: .gitignore:6:openrouterkey.txt   openrouterkey.txt
   ```

4. **No git history purge needed** — the file was never committed (confirmed above).

5. **Consider using environment variables instead of a file:**
   In `tools/decomp_work/benchmark/bench_opencode.py`, `KEY_FILE` is read from
   `openrouterkey.txt`. Switch to reading from environment variables:
   ```python
   OPENROUTER_KEY = os.environ.get("OPENROUTER_API_KEY", "")
   DEEPSEEK_KEY   = os.environ.get("DEEPSEEK_API_KEY", "")
   ```
   Set them in your shell profile or a `.env` file (also gitignored).

**Status:** This reads from an absolute path on a remote training machine
(`/storage/finetune/llm4decompile/hf_token`). The token itself is **not committed** —

## 3. If a key IS Ever Committed — Git History Purge

If you discover a key was committed (check with `git log -S "sk-or-v1" --all`), purge it:

```bash
# Install git-filter-repo
pip install git-filter-repo

# Remove the file entirely from history
git filter-repo --path openrouterkey.txt --invert-paths

# Force-push (coordinate with all collaborators first)
git push --force-with-lease origin master
```

For a literal secret embedded in source (not a standalone file):
```bash
git filter-repo --replace-text <(echo "REDACTED_ROTATED_OPENROUTER_KEY...==>REDACTED_ROTATE_ME")
```

**After purging:** all collaborators must re-clone. Notify anyone with a fork.
