# Progress chart branch

Generated by `.github/workflows/build.yml` on master. Do not edit by hand.

- `progress.png` — the chart embedded in the project README
- `progress_history.json` — one measured objdiff point per commit

This branch is deliberately separate from master: master is protection-gated
and CI cannot push to it, and keeping regenerated binaries off master's history
stops the repository growing a new copy of the image on every push.
